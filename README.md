# たべどき — Tabedoki

家庭の食品を登録し、賞味期限と消費期限を管理するモバイルファーストのWebアプリです。

## 主な機能
定番食品のカスタマイズ（追加・編集・削除）・以前の登録からの入力補完、カテゴリ・数量単位、食品の登録・編集・削除、使い切り／廃棄、期限切れ・当日・3日以内の分類、カテゴリ・場所・期限状態の絞り込み、名前検索、JSONバックアップ・復元。期限計算は端末のローカル暦日を使用します。

**データはブラウザのLocalStorageだけに保存されます。** ブラウザの履歴・データ削除、端末変更、異なるブラウザでは復元できません。定期的にJSONファイルを保存してください。

既存の食品は初回読み込みでv3へ移行し、入力済みの項目を保持します。v1食品だけはカテゴリ「その他」・単位「点」を追加します。定番と食品は一緒にJSONバックアップできます。新規登録では今回の期限日を入力してください。公開更新後は開いていたタブを再読み込みし、1つのタブで操作してください。

一覧では検索の横にある「絞り込み」からカテゴリ・保存場所・期限を選び、適用中の条件は「条件をクリア」で解除できます。廃棄・削除は各食品の「その他の操作」から行います。

定番は登録画面の「定番を編集」、またはヘッダーの「定番食品」から設定できます。定番を変更しても登録済み食品は変わりません。旧v1/v2バックアップから復元した場合は現在の定番を保持し、v3バックアップからは定番も復元します。

## 開発と検証
Node.js 24.20.0以降（`.node-version`参照）で実行します。

```sh
npm ci
npm run check
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run dev
```
